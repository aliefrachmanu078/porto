Tentang Saya

Latar Belakang & Minat Riset

Saya memiliki latar belakang pendidikan di D4 Teknologi Game dengan fokus utama pada Game Design serta pembuatan aset game 2D dan 3D. Memiliki ketertarikan mendalam terhadap riset mekanisme game dan tren perkembangannya, saya berfokus merancang alur permainan, interaksi pemain, dan membangun prototipe yang konsisten baik secara mekanik maupun visual.

Dalam proses perancangan dan produksi, saya memanfaatkan Blender untuk 3D environment & level mapping, IbisPaintX untuk 2D character art, serta didukung fondasi programming seperti Python, Java, dan PHP dengan penyimpanan MySQL dan Git untuk manajemen versi. Saya senang menyelesaikan masalah terkait penerjemahan ide/konsep abstrak menjadi rancangan game konkret—memastikan transisi antara estetika visual, tata letak map/lingkungan, dan logika alur game berjalan selaras.
